## 固定污染模型

每個事件 `i` 的觀察 Top-7 回報為 `S_i`、合資格池等權回報為 `B_i`、合資格股份數為
`N_i`。若一隻被漏掉而本來會入選的股份在持有期退出，其固定退出回報為 `L`，則：

```text
S'_i = S_i + Z_i × (L - S_i) / 7
B'_i = B_i + Z_i × (L - B_i) / (N_i + 1)
A'_i = S'_i - B'_i
```

`Z_i` 表示該事件是否受污染。候選以 1/7 承受缺失股份；公平基準亦必須把同一股份
以 `1/(N_i+1)` 納入，禁止只打擊候選或只打擊 baseline。

模型只加入一隻缺失入選股份，不假裝重建其事前動量路徑。它是對「選樣偏差集中在
入選籃子」的壓力界線，不是合成正式回測。

## 固定壓力格

- 退出回報 `L`：-25%、-50%、-80%、-100%。
- 每事件污染率 `p`：0.5%、1%、2%、5%、10%。
- 主要判讀格：`L = -50%`、`p = 2%`。
- Top-K 固定為 7；不得按結果改為 5、10 或其他數目。
- 所有 20 格完整呈現，不只展示最好或最差一格。

2% 不是估計的真實退市率；它只是低頻污染的固定主要情境。四個退出回報及五個污染率
亦不得在看到結果後加密、刪除或重排。

## 固定期望值與統計

每格先計算期望污染序列：

```text
E[A'_i] = (S_i - B_i) + p × ((L - S_i)/7 - (L - B_i)/(N_i + 1))
```

固定輸出：

1. 平均及中位配對差；
2. 配對勝率；
3. Newey–West 平均值檢驗，固定 `max_lag = 4`、每年 52 個事件；
4. 前十年（至 2016-07-29）及後十年（由 2016-08-01）的平均配對差；
5. 使平均配對差降至零的解析 break-even 污染率；
6. 使期望序列 Newey–West t 首次低於 1.96 的污染率，以固定 0.01 個百分點網格
   `0%…100%` 搜尋，不用結果後的連續優化。

## 固定 Monte Carlo

- 路徑：2,000；事件：原始 905 個，日期順序不得重排。
- 隨機種子：`20260804`。
- 先生成一個 `2000 × 905` 的均勻亂數矩陣；所有 20 格共用同一矩陣。
- 每格以 `Z = U < p` 產生 Bernoulli 污染；不得為某格重抽較有利的亂數。
- 固定輸出：路徑平均配對差的 2.5%、50%、97.5% 分位數、平均值為正的路徑比例，
  以及前後十年平均值同時為正的路徑比例。

Monte Carlo 只量化固定模型的不確定性，不把 2,000 條路徑計成 2,000 次獨立市場樣本，
亦不更新全專案搜尋次數或 DSR。

## 主要格的固定壓力生存門檻

主要格須同時符合以下五項，才可標示為「在此合成壓力下仍存活」：

1. 期望平均配對差大於 0；
2. 期望序列 Newey–West t 不低於 1.96；
3. Monte Carlo 平均值為正的路徑不少於 95%；
4. Monte Carlo 前後十年平均值同時為正的路徑不少於 90%；
5. 期望前、後十年平均配對差均大於 0。

任一項失敗即記錄負結果，不改退出回報、污染率、Top-K、持有期、成本、lag 或種子救援。
通過亦只表示這個特定合成格沒有推翻訊號，不代表通過存活者偏差、正式回測或 Paper 門檻。
