# v3 五市場機制驗證：事前凍結協議

## 凍結時間與定位

本協議在下載下列五個市場的驗證資料、查看任何跨市場績效前寫定。它是專案內
的 prospective test，不是外部註冊臨床試驗，也不會抹去先前 6,100 次搜尋。
執行器必須把本檔在首次下載前的 SHA-256 寫入結果，之後不得因結果難看而更換
市場、期間、規則或門檻。

## 固定市場與期間

五個價格指數各自使用本地交易日，不做全球日曆交集：

| Yahoo 代號 | 市場 | 指數 |
|---|---|---|
| `^GSPC` | 美國 | S&P 500 |
| `^FTSE` | 英國 | FTSE 100 |
| `^GDAXI` | 德國 | DAX |
| `^N225` | 日本 | Nikkei 225 |
| `^HSI` | 香港 | Hang Seng |

- 下載暖機起點：1987-01-01；資料截止：2006-07-28。
- 固定驗證期：1989-01-03 至 2006-07-28。
- 若某市場在驗證起點前不足 252 個有效 session，該市場判定資料失敗，不得改期。
- 使用價格指數而非總報酬指數；策略與 buy-and-hold 基準必須使用同一價格口徑。
- 防守資產固定為零報酬 `CASH`，避免用事後挑選的本國短債美化結果。

## 固定策略

逐市場套用與 v3 完全相同、不可調參的月末規則：

1. 計算該指數過去 252 個本地交易日總報酬。
2. 連續兩個月末為正才切到成長 regime；連續兩個月末不為正才切到防守 regime。
3. 成長 regime 持有該指數 100%。
4. 防守 regime 的指數權重為 `18% / 最近 21 日年化實現波動`，限制 0%–100%；
   其餘放零報酬 CASH。
5. 月末收盤產生訊號，下一個本地交易日開盤執行；10 bps 為主成本，另測 50 bps。
6. 不使用槓桿、不更換防守資產、不依市場調整目標波動或確認月數。

## 事前硬門檻

五市場驗證只有在下列全部成立時才標成 `cross_market_passed=true`：

1. 至少四個市場的完整期 CAGR 高於各自 buy-and-hold。
2. 至少四個市場的 Sharpe 高於各自 buy-and-hold。
3. 至少四個市場的最大回撤改善至少 10 個百分點。
4. 成本提高至 50 bps 後，至少四個市場的 CAGR 仍高於各自基準。
5. 每個市場的五年滾動視窗仍以至少 10 bps 年化才算有效勝出；五市場勝率中位數
   至少 60%，且至少三個市場各自達 60%。
6. 把五市場每日主動報酬先各自對齊為等權投組後，Newey–West t 值至少 1.96。
7. 至少三個市場在固定驗證期的前半與後半 CAGR 都高於各自基準。

另報告全域 6,100 次搜尋懲罰的 Deflated Sharpe、每個市場的負結果、資料涵蓋與
快照雜湊。跨市場通過只代表機制較可重現；QQQ 較舊代理、統計與 252 日／6 次
換倉 LIVE 門檻仍須各自通過，不能由本測試取代。
